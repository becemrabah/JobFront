# JobGenie Frontend

A React application to generate cover letters based on job descriptions and CVs, with editable CV input and downloadable cover letters as PDF.

## Features

- **Job Description input**: Enter the job description to tailor your cover letter.
- **Editable CV textarea**: Users can type or edit their CV directly.
- **Generate Cover Letter button**: Prepares the cover letter (demo logs to console, replaceable with API).
- **Download Cover Letter as PDF**: Export the cover letter and CV as a PDF using `jsPDF`.
- **Dark mode support**: Optional UI styling for dark mode.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/jobgenie-frontend.git
cd jobgenie-frontend
```

npm install

npm start
